## 采集要求

- **设备**：`Huawei_Tablet`（平板，2560×1600，density 360）与 `Huawei_2in1`
  （2-in-1，2160×1440，density 200；窗口最大化后 1728vp，三栏布局才会出现）。
- **尺寸**：原图 2560×1600 / 2160×1440，按原样提交，不裁剪、不加边框。
- **数据**：真实订阅源（含封面图），不出现真实账号令牌。
- **语言**：设置 → 界面语言 切换后重新采集，保证同一套截图界面一致。
- **命名**：见上表；缺图时不要放占位文件。

采集数据：四个真实订阅源（小众软件 / 少数派 / 机核 / 爱范儿，共 60 篇，均带封面）通过
「添加订阅源」按 URL 添加，未接入任何第三方账号；界面语言在应用内切换后各拍一套。

注意：2-in-1 是**窗口最大化**（1728vp）才出现侧栏常驻的三栏布局；平板（1138vp）
为抽屉式，主界面因此是「列表 + 阅读器」两栏。
## 卡片视图的取景约定

四张卡片截图都选「机核」这一源（20 篇，篇篇带封面），这样整屏卡片都有配图，
不会出现 RSS 占位图。若换成「全部文章」，少数派的条目没有封面，网格里会留下
灰色占位，观感明显变差 —— 采集卡片视图时请固定选一个图片完整的源。
